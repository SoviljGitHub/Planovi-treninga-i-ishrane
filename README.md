# Planovi treninga i ishrane

Veb prezentacija namenjena korisnicima koji žele da unaprede svoje fizičko
zdravlje kroz pravilnu ishranu i strukturirane planove vežbanja.

## Tehnologije

- HTML5
- CSS3
- JavaScript

## Funkcionalnosti

- Višestranična (multi-page) veb aplikacija
- Responzivan dizajn za različite uređaje
- Navigacioni i padajući meni
- Hamburger meni za mobilne uređaje
- Interaktivni slajder slika
- HTML i JavaScript validacija forme
- Animacije i vizuelni efekti
- Svetla i tamna tema
- Podešavanje veličine fonta
- Čuvanje podešavanja pomoću cookies
- Promena jezika između srpskog i engleskog
- SEO optimizacija
